# 캐러셀 주제 선정·자료조사 가이드 (insu_secretnote)

캐러셀은 주제와 자료가 8할이다. 디자인을 손보기 전에 이 문서대로 주제를 고르고 사실을 확인한다. 계정 규칙은 `generator/INSTAGRAM.md`, 제작 도구는 `generator/carousel/kit.py`·`covers.py` 를 따른다.

## 1. 좋은 주제의 조건

본부장님이 정한 기준: 페이지마다 정보가 많아 오래 머물고, 보는 사람이 "이건 몰랐네, 가족·친구한테 보내야겠다" 싶어야 한다.

아래 다섯 개 질문에 모두 "예"가 나와야 후보가 된다.

| 질문 | 통과 예시 | 탈락 예시 |
|---|---|---|
| 1. 모르면 실제로 돈을 잃거나 못 받는가? | 지정대리청구인 안 하면 치매보험 청구 못 함 | 보험의 종류 정리 |
| 2. 대부분 처음 듣는 내용이거나, 지금 커뮤니티에서 많이 묻는 내용인가? | 현장조사 때 서명하면 안 되는 서류 | 실손보험이 뭔지 |
| 3. 보낼 사람이 바로 떠오르는가? (부모님·배우자·형제·친구) | 부모님 보험 있는 집 | 설계사만 관심 있는 수수료 이야기 |
| 4. 공식 출처로 확인되는 숫자·제도가 있는가? | 금감원 지정률 23.1% | 카더라, 커뮤니티 후기 |
| 5. 9장을 채울 만큼 내용이 깊은가? (이유·해결·순서·예외·Q&A) | 제도 + 바뀐 점 + 신청 순서 + 헷갈리는 질문 | 한 줄 팁 |

**우선순위 (위에서부터)**
1. 최근 바뀐 제도·새로 생긴 제도 (시행일이 있는 것): "2026년 ○월부터"는 가장 강한 훅이다.
2. 모르면 못 받는 돈: 숨은 보험금, 청구 기한, 놓치기 쉬운 특약, 재청구.
3. 보험사와 갈등이 생기는 순간의 대처: 현장조사, 부지급 통보, 감액, 분쟁 조정.
4. 가입·해지 직전에 꼭 확인할 것: 해지 전 체크, 갈아타기 손해, 알릴의무.
5. 가족 단위 점검: 부모님 보험 점검, 자녀 보험, 신혼부부.

## 2. 지금까지의 데이터 (주제 고를 때 근거)

- 인스타 최고: "현장조사 이 서류 서명 금지" 약 1300뷰, 간병인보험 약 2000뷰. 공통점은 "보험사와 맞서는 순간"과 "가족을 돌보는 상황".
- 부모님 치매보험 영상은 약 400뷰로 낮았다. 같은 대상이라도 "받는 법"보다 "못 받는 이유·반전"이 반응이 좋다.
- 업계 상위 보험 릴스(2026-11 분석): 제도 변경 마감, 통념 뒤집기 훅이 강하다.
- 반응 좋은 정보 캐러셀: 저장·공유가 많은 것은 체크리스트·순서·비교표가 들어 있는 것이다.
- 성과는 조회수보다 **저장·공유**로 판단한다. 월요일 리포트에서 캐러셀 성과가 쌓이면 이 칸을 갱신한다.

## 3. 시리즈와 주제 후보

시리즈로 묶으면 "다음 편"을 기다리게 만들 수 있다. 마지막 장에서 다음 편을 예고한다.

**몰라서 못 받는 보험금**
- ① 지정대리청구인 (c01 완료)
- ② 숨은 보험금 3분 만에 찾는 법 (c01에서 예고함, 다음 순서로 우선)
- 보험금 청구 기한 3년, 지나면 끝일까
- 실손 소액 청구, 안 하고 버리는 돈
- 후유장해 진단, 나중에 다시 청구할 수 있는 경우
- 진단비와 수술비, 같이 받을 수 있는데 모르는 경우

**보험사가 먼저 말 안 해주는 것**
- 현장조사 나왔을 때 하면 안 되는 것 (인스타 최고 반응 주제의 캐러셀 확장판)
- 보험금 부지급·감액 통보를 받았을 때 순서 (금감원 분쟁조정 등)
- 의료자문 동의서, 꼭 해야 할까

**해지·갈아타기 전에**
- 해지 전에 확인할 5가지
- 갈아타기(승환) 손해 보는 경우
- 보험료 못 낼 때 해지 말고 쓸 수 있는 제도 (납입유예·감액완납 등)

**우리 가족 보험 점검**
- 부모님 보험, 명절에 확인할 것
- 신혼부부 보험 합칠 때
- 아이 보험, 성인 되면 바뀌는 것

후보는 예시다. 블로그·커뮤니티에서 지금 이슈되는 키워드가 있으면 그쪽이 먼저다. 실제로 쓸 때마다 최신 자료로 다시 확인하고, 시점이 맞는 주제(명절, 연말정산, 제도 시행일)를 먼저 고른다.

## 4. 자료조사 순서

1. **사람들이 몰리는 곳에서 이슈 찾기 (주제 발굴, WebSearch 5~8회)**
   - 블로그·커뮤니티가 사람이 가장 많이 몰리는 곳이다. 여기서 지금 이야기되는 보험 키워드를 먼저 잡는다.
   - 찾을 곳: 네이버 블로그·카페·지식iN(보험 질문), 맘카페, 보배드림(자동차보험·사고), 더쿠·네이트판·블라인드(직장인·가족 이야기), 클리앙·뽐뿌(실손·청구 후기), 유튜브 댓글, 다른 보험 인스타·쓰레드.
   - 검색 예: "실손 청구 거절 후기", "보험금 부지급 카페", "현장조사 나왔어요", "보험 해지 고민 지식인", "부모님 보험 정리 맘카페", "보험사 손해사정 억울".
   - 볼 것: 같은 고민이 여러 글에 반복되는가, 댓글·조회가 많은가, "이거 몰랐다"는 반응이 있는가, 사람들이 실제로 쓰는 단어는 무엇인가.
   - 잡은 키워드는 표지 제목과 캡션에 사람들 말투 그대로 쓴다(예: "보험사가 서명하래요", "청구했더니 거절").
   - 네이버 페이지는 WebFetch 로 열리지 않을 때가 많다. 검색 결과의 제목·요약으로 판단하고, 필요하면 같은 이야기를 다룬 다른 글을 연다.
2. **공식 이슈와 맞춰 보기 (WebSearch 2~3회)**
   - 커뮤니티에서 잡은 키워드와 관련된 금감원·금융위 보도자료, 법령 개정, 언론 기사를 찾는다. "커뮤니티에서 다들 헷갈려 하는 것 + 공식 답"이 가장 좋은 조합이다.
3. **후보 3개 압축**: 1장의 다섯 질문으로 점수를 매긴다(각 0~2점, 10점 만점). 7점 이상만 남긴다.
4. **원문 확인 (WebFetch)**: 고른 주제의 핵심 숫자·날짜·조건을 원문에서 직접 읽는다.
5. **교차 확인**: 숫자 하나당 출처 2곳 이상. 공식 출처가 하나라도 있어야 한다.
6. **9장 뼈대 짜기**: 아래 5장 구조에 맞는 내용이 다 나오는지 본다. 비는 칸이 있으면 주제를 바꾼다.

## 5. 출처 등급

| 등급 | 출처 | 쓰는 법 |
|---|---|---|
| 1 | 금융감독원·금융위원회 보도자료, 법령(국가법령정보센터), 생명·손해보험협회, 보험개발원, 통계청 | 숫자·제도의 근거. 장 하단에 출처 표기 |
| 2 | 주요 언론(연합뉴스, 경제지), KDI 경제정보센터 | 1등급 원문을 찾는 길잡이, 교차 확인용 |
| 3 | 보험사 공식 안내 | 절차 설명에만. 특정 보험사 이름은 화면에 쓰지 않는다 |
| 주제 발굴용 | 블로그, 카페, 지식iN, 커뮤니티, 다른 보험 SNS, 유튜브 댓글 | 무엇이 이슈인지, 사람들이 어떤 말로 고민하는지 찾는 데 적극 쓴다. 단 숫자·제도의 근거로는 쓰지 않고, 같은 내용을 1·2등급 출처로 반드시 확인한다. 개인 사연은 그대로 옮기지 않고 상황만 각색한다 |
| 쓰지 않음 | AI 요약, 출처 없는 짤 | 쓰지 않는다 |

- 보도자료 날짜와 시행일을 구분한다. "발표"와 "시행"을 섞지 않는다.
- 보험사·상품마다 다른 내용은 "보험사·상품에 따라 다를 수 있어요"를 해당 장 하단에 적는다.
- 확인이 안 되는 숫자는 쓰지 않는다. 비율로 계산한 숫자(예: 100% − 23.1% = 77%)는 원래 숫자를 함께 보여준다.

## 6. 9장 기본 구조

| 장 | 역할 | 예시 (c01) |
|---|---|---|
| 1 | 표지 (covers.py 틀, 번호 순서) | 보험회사는 알고 자식들만 모르는 '이것' |
| 2 | 왜 문제인가 (이유 3가지) | 왜 못 받는 걸까요? |
| 3 | 핵심 해결책 + 숫자 (움직이는 장 가능) | 지정대리청구인, 지정률 23.1% |
| 4 | 바뀐 점·비교표 | 기명 vs 무기명 |
| 5 | 범위 넓히기 (나도 해당되나) | 암·뇌·심장 보험도 |
| 6 | 지금 할 순서 (번호 단계) | 확인 순서 5단계 |
| 7 | 헷갈리는 질문 Q&A 4~5개 | 오래된 보험도 되나요? |
| 8 | 보너스 정보 + 다음 편 예고 | 숨은 보험금 10조 |
| 9 | 공유 유도 + 체크리스트 + 랜딩 | 부모님께 보내 주세요 |

## 7. 금지·주의 (금소법 자가 점검)

- 특정 보험사·상품명, 설계사 이름·소속·연락처 노출 금지.
- "무조건", "100%", "최고", "반드시 받는다" 같은 단정·과장 금지. 가입 권유 문구 금지.
- 보험사 비방 금지. 구조와 제도를 설명하고, 행동을 안내한다.
- 공포 조장 대신 "몰랐던 사실" 프레임.
- 사진 속 인물을 질병 당사자로 단정하지 않는다.
- 문장 사이 대시(—) 금지, 캡션 한 줄 25자 안쪽.

## 8. 기록

- 주제를 확정하면 `generator/carousel/topics.csv` 에 한 줄 추가한다: `id,date,series,topic,cover,score,sources`.
- 직전 30일 안에 쓴 주제·같은 시리즈 같은 편은 다시 쓰지 않는다.
- 에피소드 파일 맨 위 주석에 출처 원문 제목과 날짜를 적고, `SOURCES` 에 주소를 남긴다.
