# 인스타그램 운영 통합 노트

여러 대화에서 정한 인스타 관련 규칙과 현황을 한곳에 모은 문서다. 인스타 작업(릴스·캐러셀·프로필·광고·랜딩)을 시작하는 대화와 예약 작업은 이 문서를 먼저 읽는다. 세부 제작 절차는 각 계정의 플레이북을 따른다.

- 본부장님: 전성재. 개발 초보. 결과물과 알림은 텔레그램 @Jerryblogbot 으로만 받는다(압축파일 말고 개별 이미지·영상).
- 공개 저장소다. 토큰·비밀번호·전화번호·개인정보는 이 문서에 적지 않는다.
- 마지막 정리: 2026-11-11

## 2. insu_secretnote (보험비밀노트)

**브랜드**
- 채널명 "보험설계사의 비밀노트", 줄여서 보험비밀노트. 문구는 "현직 설계사가" 대신 "보험회사 몰래 적어둔".
- 마스코트 비노(스프링노트 캐릭터). 포즈 12종: 기본 base · 쉿 shh · 헉 wow · 체크 check · 고민 think · 버럭 angry · 시무룩 sad · 만세 cheer · 돋보기 search · 돈 money · 콕 point · 멈춰 stop. 파일은 `generator/kit/mascot/`.
- 폰트: Paperlogy(제목·본문), 깍두기 도면체(숫자 포인트), 나눔펜(손글씨), 차이 라이징체·오이냉체(비공개 저장소 insu-assets, 공개 저장소에 복사 금지).
- 프로필 링크: insusecretnote.com

**릴스** (자세한 절차: `generator/PLAYBOOK.md`)
- 하루 2개 13:00·18:00, 인스타 릴스 + 유튜브 쇼츠 동시.
- 아침 텔레그램 주제 제안 → 12시 전 승인 → 제작·예약 게시. 승인 없으면 그날은 쉼.
- 30~50초, 1.2배속 수준의 빠른 편집, 공백 최소화. 포맷 로테이션(흰 노트·다크노트·카톡·잠금화면), 같은 포맷 연속 최대 3개, 여성 목소리 약 40%.
- 화면: 요소는 중앙, 릴스 UI(오른쪽 아이콘·하단 캡션)에 가리지 않게. 상단 브랜드줄·하단 안내문구·심의필 넣지 않음.
- 실험 축과 기록: `generator/shorts/rotation.json`, `generator/shorts/experiments.csv`.

**캐러셀** (도구: `generator/carousel/kit.py`, 에피소드: `generator/carousel/episodes/cNN.py`)
- 페이지당 정보량 많게, 오래 머무르고 "이건 몰랐네, 가족한테 보내야겠다" 싶은 내용. 시리즈 형식(예: 몰라서 못 받는 보험금 ①). 9장 안팎, c01 분량이 기준.
- 표지는 본부장님이 고른 틀 4종을 순서대로 돌린다(2026-11-11 확정, 코드 `generator/carousel/covers.py`). 에피소드 번호 순서: A1 → B1 → A2 → B2 → 다시 A1.
  - A1 사진 전면 + 하단 제목 (비밀형 훅: "보험회사는 알고 자식들만 모르는 '이것'")
  - B1 제목 위 + 비노 가운데 (반전형: "보험료 다 냈는데 보험금은 0원?")
  - A2 사진 위 + 제목 아래 (질문형: "치매에 걸리면 누가 청구하죠?")
  - B2 큰 숫자 + 비노 옆 (숫자형: "23.1%")
- 표지에는 상단 시리즈 문구·페이지 번호를 넣지 않는다. 고정: 어두운 배경, Paperlogy 제목, 하단 계정 줄. 바꾸는 것: 사진, 비노 포즈(같은 포즈 주 1회), 강조색(노랑·빨강·파랑), 훅 유형.
- 사진은 얼굴보다 손·뒷모습·풍경 위주. 인물을 질병 당사자로 단정하지 않는다.
- 비노는 모든 장에 넣지 않는다. 표지 B와 내용상 필요한 1~2장에만.
- 움직이는 장(mp4)은 무음으로 만든다. 배경음악은 본부장님이 모바일 업로드 때 직접 넣는다.
- 자동 업로드 안 함. 텔레그램 앨범 전송까지만 하고 업로드는 본부장님이 직접.

**성과 메모**
- 2026-11 초: 간병인보험 약 2000뷰, 부모님 치매보험 약 400뷰.
- 2026-11-10: 인스타 최고 "현장조사 이 서류 서명 금지" 약 1300뷰, 유튜브 최고 "보험 해지 전 이것부터" 약 200뷰. 나머지 인스타 100뷰 안팎.
- 결론: "진짜 몰랐는데?" 싶은 정보, 팔로우하면 이득인 정보성 콘텐츠 우선.
- 업계 상위 보험 릴스 분석(2026-11, Apify 285개 수집): 제도 변경 마감(5세대 실손 전환 등)·통념 뒤집기 훅이 강함. 상위 영상 문구 중 금소법상 위험한 표현이 있으니 그대로 쓰지 말 것.
- 반응 좋은 정보성 캐러셀 공통점: 큰 시각 요소 하나, 2~3줄 제목, 강조색 한 가지, 궁금증 훅, 작은 카테고리 라벨.

**랜딩 insusecretnote.com**
- Cloudflare Pages 프로젝트 bohum-secret-note (예전 주소 bohum-secret-note.netlify.app 도 남아 있음).
- 구조: 홈 → 주제별 페이지(dementia, care, cancer, silson, 20s, checkup) → 자가 체크 → 상담 신청(apply). 정보를 먼저 보여주고 상담 니즈가 높은 사람만 신청하도록.
- 신청 폼: 대면/비대면 선택, 대면은 수도권·충청권·강원권만. 하단 회사 안내문구 없음.
- 데이터: Supabase bsn_leads → 구글 시트 → 텔레그램 알림. 폼·시트 연동 코드는 건드리지 않는다.
- 심의필·등록번호는 아직 비어 있음(심의 후 본부장님이 직접 추가).
