**수집 권한 부족 1: 인스타 조회·저장·공유 (에러 #10 "Application does not have permission")**
- 원인: 메타 앱에 instagram_manage_insights 권한이 없는 토큰을 쓰고 있다. 그래서 좋아요·댓글만 모이고, 이번 주 재생수는 공개 데이터로 따로 채웠다. 저장·공유·시청 지속률은 볼 수 없다.
- 해결(본부장님이 직접, 약 10분):
  1. developers.facebook.com 접속 → 내 앱 → 보험비밀노트 게시용 앱 선택.
  2. 왼쪽 "사용 사례" 또는 "앱 검수 → 권한 및 기능"에서 instagram_manage_insights 를 찾아 "추가".
  3. 도구 → 그래프 API 탐색기에서 같은 앱 선택 → 권한에 instagram_basic, instagram_content_publish, instagram_manage_insights, pages_show_list, pages_read_engagement 체크 → "Generate Access Token".
  4. 액세스 토큰 디버거에서 "액세스 토큰 연장"으로 장기 토큰(60일) 받기.
  5. GitHub 저장소 insu-photobank → Settings → Secrets and variables → Actions → IG_TOKEN 을 "Update" 로 새 토큰 붙여넣기.
  6. 텔레그램으로 "토큰 바꿨어" 라고 보내 주시면 다음 리포트부터 저장·공유까지 정리한다.

**수집 권한 부족 2: 유튜브 통계 (403 "insufficient authentication scopes")**
- 원인: 업로드용 토큰에 youtube.readonly 범위가 없다.
- 해결(본부장님이 직접, 약 10분):
  1. developers.google.com/oauthplayground 접속 → 오른쪽 위 톱니바퀴 → "Use your own OAuth credentials" 체크 → 저장소 Secrets 에 넣었던 것과 같은 Client ID·Client Secret 입력.
  2. 왼쪽 범위 입력칸에 `https://www.googleapis.com/auth/youtube.upload https://www.googleapis.com/auth/youtube.readonly` 를 띄어쓰기로 함께 넣고 "Authorize APIs" → 보험 비밀노트 채널 계정으로 로그인·허용.
  3. "Exchange authorization code for tokens" 클릭 → 나온 Refresh token 복사.
  4. GitHub → Settings → Secrets and variables → Actions → YT_REFRESH_TOKEN 을 "Update" 로 붙여넣기.
